# UniteDesk v0.1.0 — Developer Preview

The first public developer preview of UniteDesk is ready to explore. **[Try the browser demo](https://nokibuzz.github.io/unitedesk/)** or clone the repository to connect your own tools locally.

## Included

- Active sprint and Daily mode for Jira, Linear, and mock data, with configurable status mapping.
- GitLab or GitHub Review Queue, with personal views and advanced filters.
- Searchable Knowledge view with Confluence, Notion, and GitHub Markdown adapters.
- Useful links with fuzzy search from any page.
- Scrum Poker and Team Retrospective with action items and a PDF report on the local server.
- Light and dark themes, team and personal settings, synthetic demo data, and setup documentation.
- Contribution, issue, pull request, conduct, and private security reporting paths for new collaborators.

## Try it locally

Requires Node.js 22.12+ and npm 10+.

```bash
git clone https://github.com/nokibuzz/unitedesk.git
cd unitedesk
npm ci
npm run mock:seed
npm run dev
```

Read [the integration guide](https://github.com/nokibuzz/unitedesk/blob/main/docs/integrations.md) before connecting provider accounts.

## Preview limitations

The public GitHub Pages demo uses synthetic records. Its Poker and Retro sessions are browser-local and are not shared between visitors. The local API has **no user authentication**; keep it on localhost or a trusted LAN/VPN and do not expose it directly to the internet. Provider data is generally read-only; explicit Jira story-point publishing from Poker is the current limited write action. Document editing, broad ticket status actions, and public multi-tenant hosting are not included.

Feedback is welcome through [issues](https://github.com/nokibuzz/unitedesk/issues). Report security problems through [private vulnerability reporting](https://github.com/nokibuzz/unitedesk/security/advisories).
